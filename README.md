# Fibonacci Series in C++

A simple C++ program that generates and displays the Fibonacci series up to a user-specified number of terms.

### Concepts Used

* C++ Classes and Objects
* Member Functions
* `for` Loop
* User Input and Output
* Fibonacci Sequence
* Basic Object-Oriented Programming (OOP)

### How It Works

The program starts with `0` and `1`. Each subsequent Fibonacci number is calculated by adding the previous two numbers.

For example, if the user enters `7`, the output will be:

```text
0
1
1
2
3
5
8
```

This project was created as a basic practice project for understanding **C++ OOP and iterative programming**.
